# TravelTrucks

## Description

TravelTrucks is a frontend web application for a camper rental service.  
Users can browse available campers, filter them based on preferences, view detailed information, and make bookings.

## Features

- Camper catalog with filters
- Backend pagination
- Favorites
- Camper details page
- Booking form
- Reviews

## Tech stack

Next.js, TypeScript, Zustand, Axios

## Installation

npm install
npm run dev
